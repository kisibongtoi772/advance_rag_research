# Advanced RAG Framework

A modular, clean-architecture framework for building, testing, and evaluating Advanced RAG (Retrieval-Augmented Generation) systems.

## Features
- Modular interfaces for Loaders, Embeddings, Vector Stores, Retrievers, and Generators.
- Built-in CLI for easy execution and testing.
- Integration ready with Ragas for RAG evaluation.

## Installation

```bash
cd advance_rag_research
pip install -e .
```

## Usage

```bash
rag-framework --help
rag-framework evaluate --config configs/test.yaml
```
